# Automatisering Event Aanvraag

Dit project automatiseert de verwerking van event-aanvragen volgens de **BOS-architectuur** (Blueprints, Orchestrators, Systems).

## Structuur
- `blueprints/`: Operationele instructies (Markdown).
- `systems/`: Uitvoerende Python-scripts.
- `CLAUDE.md`: AI-instructies en context.

## Gebruik
1. Voeg credentials toe aan `.env`.
2. Volg de instructies in de Blueprints voor specifieke workflows.
